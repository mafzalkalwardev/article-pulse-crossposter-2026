What is Article Pulse?

Article Pulse is a publishing workspace made by INDUS Web Agency. It keeps Markdown articles, a content identity, and connections for Hashnode and dev.to in one workflow. Deterministic mode writes suggestions with local templates and no AI service. With your own Supabase project, the same app can encrypt provider secrets, store drafts, and publish or schedule them.

  • Markdown source
  • Hashnode and dev.to
  • Public GitHub evidence
  • Encrypted secrets
  • Drafts stay drafts

Features

What the repository actually does

Each item below is implemented in the Next.js workspace, the local control room, or both. Nothing here is a usage statistic.

01

Markdown, with a publish flag

Articles use YAML front matter for title, description, tags, cover image, canonical URL, and publish. The local queue lists a file as Ready only when it contains publish: true. Generated growth drafts start with publish: false.

02

Hashnode and dev.to

The hosted adapters call Hashnode's GraphQL API and the dev.to articles API. A canonical URL is sent as originalArticleURL on Hashnode and canonical_url on dev.to. Hashnode receives up to five tags. dev.to receives up to four.

03

Suggestions from public evidence

A sync reads a public GitHub profile and at most 100 repositories, then returns at most three suggestions. Deterministic titles, questions, solutions, and tags come from local templates plus the topics, audience, tone, and formats you saved.

04

A market estimate you can read

The dashboard can query public Hacker News discussions for up to three topics. It estimates opportunity from relatedness, conversation volume, points and comments, freshness, and repository fit, and it labels a format such as a case study or practical guide. The score is not a ranking promise.

05

Encrypted connections

With Supabase, sign-in is a magic link. Provider secrets are encrypted with AES-256-GCM before storage. Profiles, connections, and articles use row-level security. Hashnode tokens are checked against the publication before they are saved. The manual publish route rejects an article already marked published.

06

A schedule, and an optional AI mode

You can save a daily publish hour. A Vercel cron route runs every 15 minutes and publishes due articles when the request presents CRON_SECRET. Unconnected platforms are reported as failures. AI mode is off unless you select it and configure a server-side OpenAI-compatible endpoint. If that provider fails, the request fails instead of switching modes.

How it works

Publish a reviewed article to Hashnode and dev.to

Use Article Pulse to sync a public GitHub profile, save a reviewable Markdown draft, connect Hashnode or dev.to, and publish or schedule the article. You need Node.js 20 or newer, the public GitHub repository, and a public GitHub profile URL. Live publishing also needs your own Supabase project.

  1. Clone the repository and install dependencies

    Clone the Article Pulse repository from GitHub and run npm install. The app expects Node.js 20 or newer.

  2. Start the workspace

    Run npm run dev and open the local URL that Next.js prints. Without Supabase environment variables, the sign-in page stays in demo mode and you can open the dashboard without an account.

  3. Save a content identity

    Enter a public github.com profile URL, then save topics, audience, tone, article formats, image style, and an alt-text rule. Leave intelligence mode on Deterministic unless you have configured an AI provider.

  4. Sync public GitHub data

    Connect the GitHub profile. Article Pulse reads public profile and repository fields from api.github.com, using at most 100 repositories, and returns at most three article suggestions.

  5. Review the market estimate

    Choose Research market and rank ideas to query public Hacker News stories for up to three topics. The dashboard attaches an opportunity estimate and says that scores do not guarantee ranking.

  6. Create a reviewable draft

    Choose Create reviewable draft on a suggestion. Demo mode stores the Markdown in browser local storage. With Supabase configured, the draft is saved to your articles and is not published by that action.

  7. Connect a platform and publish or schedule

    Apply the SQL files supabase/migrations/001_initial.sql and supabase/migrations/002_content_identity.sql to your Supabase project, then set the Supabase URL, keys, and APP_ENCRYPTION_KEY from .env.local.example. Sign in with a magic link and save a dev.to API key or a Hashnode personal access token plus publication ID. Hashnode is verified before the secret is encrypted with AES-256-GCM. Publish the reviewed article, or mark it scheduled and enable automatic publishing so the cron route can send it.

Install on your machine

These are the workspace commands. Copy .env.local.example to .env.local only when you are ready to connect your own Supabase project.

git clone https://github.com/mafzalkalwardev/article-pulse-crossposter-2026.git
cd article-pulse-crossposter-2026
npm install
npm run dev

Local control room

The repository also serves a local dashboard. npm start runs next start, so start this server with Node directly. It exposes GET /api/health and GET /api/articles. POST /api/growth/generate reads the public GitHub user in GITHUB_USERNAME, writes a Markdown draft under articles/, and writes an SVG cover under assets/generated/.

node server.js

Then open http://localhost:4173. Generated drafts use publish: false unless GROWTH_AUTO_PUBLISH is true.

Boundaries

Operational boundaries

  • The repository does not publish a price, a user count, a rating, or a delivery-success rate.
  • No license is declared yet. The README says to choose a license before accepting outside contributions.
  • Demo mode does not store a live Hashnode token. Credentials belong in your environment, not in the git history.
  • Deterministic mode calls the public GitHub API for profile data. Market research calls the public Hacker News search API. Optional AI mode sends only a bounded public summary to an endpoint you configure, and those provider credentials are not sent to the browser.
  • Hosted GitHub connect, when GITHUB_CLIENT_ID is set, starts OAuth with the read:user and repo scopes. That path is separate from demo mode.
  • A public GitHub repository does not make the scheduler a shared service. The cron route runs in your Vercel project and requires CRON_SECRET.
  • Hashnode API publishing may require that publication's Pro plan and permission to publish. That is a Hashnode requirement, not a price for Article Pulse.
  • The README describes a dry run as a planned workflow step. The current routes do not expose a separate dry-run command.

FAQ

Questions

What is Article Pulse?

Article Pulse is a publishing workspace from INDUS Web Agency. It turns public GitHub evidence into reviewable Markdown drafts and can publish an approved article to Hashnode and dev.to.

Does Article Pulse require an AI service?

No. Deterministic mode is the default and uses JavaScript templates, not an AI SDK or model endpoint. AI-assisted mode runs only if you select it and set INTELLIGENCE_PROVIDER_URL and INTELLIGENCE_API_KEY on the server.

Where do API tokens go?

In the hosted app they are encrypted with AES-256-GCM and stored in your Supabase project. They are not committed to the repository. Demo mode keeps preferences in browser local storage and does not store a live Hashnode token.

Which sites can it publish to?

Hashnode, using the Hashnode GraphQL API, and dev.to, using the dev.to articles API. A canonical URL can be sent with both requests. Hashnode receives up to five tags, and dev.to receives up to four.

Will it post an article before I review it?

No. Local growth drafts are written with publish set to false unless GROWTH_AUTO_PUBLISH is true. Creating a draft in the dashboard does not publish it. Automatic publishing sends only articles whose status is scheduled.

What does an opportunity score mean?

It is an estimate built from public Hacker News conversation volume, points, comments, freshness, and how well the idea fits the repositories that were synced. It is not a prediction that an article will rank.

How many suggestions does one sync return?

At most three. A sync reads at most 100 public repositories. Demo mode also allows at most six GitHub sync requests per minute per running process.

How much does Article Pulse cost?

The repository does not list a price. You run it with Node.js 20 or newer. Hosted accounts and scheduled publishing use your own Supabase and Vercel projects. Hashnode's API may separately require that publication's Pro plan.

Is the source licensed?

The source is public on GitHub, and the repository does not declare a license yet. The README says to choose a license before accepting outside contributions.

Who makes Article Pulse?

INDUS Web Agency, the studio at induswebagency.com. The source code is the public GitHub repository mafzalkalwardev/article-pulse-crossposter-2026.

How do I install it?

Clone the GitHub repository, run npm install, then run npm run dev for the workspace. Run node server.js to open the local control room on port 4173.
